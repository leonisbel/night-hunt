Locker🪙 0

Owner admin

Locked. Night Hunt does not grant admin because you host a room or because your name is Leo. There is no password in this build. To turn it on, run your own authoritative server, verify Leo with an identity provider you control, and set globalThis.NH_OWNER_CHECK on that server to a function that returns true only after the check. The site and the Windows wrapper do not set that function, so commands stay off.

Commands that exist behind that check: kick a player, end the round, grant a small coin amount. They do nothing while the check is missing.
